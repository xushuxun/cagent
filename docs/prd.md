# 企业经营历史重放 Agent PRD

定位：AI 版的穆迪手册（Moody's Manuals）与价值在线（Value Line）。

巴菲特和芒格常年翻阅的两套工具：穆迪手册提供每家公司密集的事实档案（业务、财务、沿革、管理层，几十年不变的形式）；价值在线用全市场统一的单页格式陈列十几年财务序列与关键指标，任何公司横向可比。两者共同点：事实密度极高、格式标准化、时间序列长、不下投资结论——判断留给读者。

我们做的事：AI 承担当年分析师的手工汇编（读几百页年报、抽取、核对、排版），产品形态继承这两套手册的纪律——标准化、可追溯、跨年积累。

## 心得（原型迭代积累）

只声明原则，不记实现细节。

- 做信息的生产者，不做信息的搬运工。机器能算出的、别处能查到的，都不是产品；只有通读全文之后才能组织出来的知识才是。
- 形式追随结构。价值链、组织树、对照表各有其形，先看清信息本身的结构，再选容器；用错容器，正确的内容也会读歪。
- 图管关系，表管数量，文管叙述。一个区块只承担一种职责。
- 描述组织，先于描述人。投资者要理解的是权力如何分配、能力置于何处，而不是谁的年龄和薪酬是多少。
- 信任是省略声明的结果。通篇标注"经核验""不评判"，恰恰说明内容没站住；事实摆对了，结论读者自会得出。

## 资本回报的设计原则

**买生意，不买代码。**
芒格：长期看，股票的回报很难显著超过底层生意的回报。市场短期是投票机，长期是称重机，秤称的是生意，不是情绪。我们描述的是生意为资本工作的能力，不是价格表现。

**会计利润不是真利润，所有者收益才是。**
巴菲特 1986 年信：净利润 + 折旧摊销 − 维持竞争地位与产销规模所需的资本开支（及必要营运资本增量）。过滤后剩下的，才是这一年真正赚到、可以拿走的钱。

**留存的每一元要通过一元检验。**
巴菲特 1984 年信：留下不分红的利润，必须在随后几年为股东创造至少一元的价值。对错不在分不分，在留下的钱变成了什么。

**高 ROE 不靠杠杆才是质量，核心是增量资本回报。**
重要的不是去年赚多少，而是再投进去的每一元赚多少。ROE 15%、增量回报 5% 的公司，增长越多，毁损越多。

**回报以公司整体股东口径计。**
价值投资买下的是整门生意，关心的是全体股东的资本整体变大了多少：归母净利润、归母净资产、分红总额的整体增长。回购注销与增发稀释是资本配置事件，在资本去向里陈述事实即可，不做每股折算——每股数字是交易员的口径，不是企业主的口径。

**增长有盈亏分界线：增量回报 vs 资本成本。**
增长要花股东的钱，每一元要付"资金租金"。高于资本成本，增长创造价值；低于，报表越繁荣，毁损越实在。好坏与增速高低、规模大小无关，只看这一条（格林沃德）。

**分界线由护城河把守。**
没有护城河，高回报终被竞争拉平到资本成本。赚钱的增长——有机增长、技术与分销创新、核心与邻近市场扩张、无主导者的处女市场——都以护城河为前提；无护城河的扩张、进攻别人护城河守着的市场，白忙甚至送死。市场萎缩时反直觉：优势企业受害最重，超额回报消失、规模经济变成固定成本包袱，护城河变成负债。

### 推论：真正的价值投资回报是什么

```
真钱（所有者收益口径）
   ├─ 分给股东  → 分红，即时的现金回报
   └─ 留存再投  → 增量回报 × 再投资年数
                    仅当回报高于资本成本、且有护城河守住分界线
真实回报 = 分红累计 + 留存利润的复利增长（归母整体口径）
```

ROE、EPS、净现比都只是这条链上的片段，单看无意义——比率表不是错，是不完整。

### 反过来想：什么样的资本回报在撒谎

- 报 ROE 不报杠杆——债务撑起的回报率，利率上行、收入下滑时同时坍塌；
- 报每股增长不报整体——总股本扩张时，每股数字会掩盖对股东的摊薄；
- 报净利润不报所有者收益——应收账款与资本开支不足堆出来的利润，拿不走；
- 报留存不报增量——钱留下了，说不清变成了多少利润，一元检验必然不及格；
- 报增长不报回报与护城河——增长可能正在毁灭价值，而外推出来的增长率预测系统性高估。
