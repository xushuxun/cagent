# 企业经营历史重放 Agent PRD

定位：AI 版的穆迪手册（Moody's Manuals）与价值在线（Value Line）。

巴菲特和芒格常年翻阅的两套工具：穆迪手册提供每家公司密集的事实档案（业务、财务、沿革、管理层，几十年不变的形式）；价值在线用全市场统一的单页格式陈列十几年财务序列与关键指标，任何公司横向可比。两者共同点：事实密度极高、格式标准化、时间序列长、不下投资结论——判断留给读者。

我们做的事：AI 承担当年分析师的手工汇编（读几百页年报、抽取、核对、排版），产品形态继承这两套手册的纪律——标准化、可追溯、跨年积累。

## 企业 wiki

所有企业通用内容

- 生意过程简介
- 主要产品
- 公司人事组织架构
- 历史财务总结，资本回报总结（要巴菲特芒格价值投资式的资本回报，不要简单的财务计算）

## 心得（原型迭代积累）

只声明原则，不记实现细节。

- 优势区即生存区：行情软件里哪里都能看的数据（五年财务、ROE、费用表）不做，AI 重述没有增量；只做"读完全文才能编出来"的内容——生意怎么转、组织怎么设计、品牌矩阵什么样。
- 图表按信息结构选型，不为统一而统一：顺序流转用价值链（经营过程还要补回流线，过程是循环不是直线）；层级从属用组织树（架构不是流水线）；表格只留给真正的对照关系。
- 图内不放数字：经营过程图表达机制和流向，数字放表格。图的职责是结构，表的职责是数量。
- 人事组织架构要呈现组织设计：权力怎么分（委员会与职权）、业务怎么分（品牌公司矩阵）、能力放在哪（自研+体外生态）、人从哪里来（内部提拔）；罗列人名和年龄是年报本身就能给的。
- 删掉一切出处定位和解读性注脚：年报章节名、出处列、"只描述不评判"口号、净现比归因这类解读，都干扰阅读；产品的可信度靠内容本身，不靠声明。
- 通用推算值不做：单车收入之类谁都能算，且容易口径出错（曾发现 16.8 万与 14.8 万两个口径混用），除非是本产品独有的分析。
