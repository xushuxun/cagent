# Cagent PRD — AI 版《穆迪手册》与《价值在线》

## 产品目标

替价值投资者省下翻阅公司的时间。输入一家公司的历年财报，产出一份能快速读完、每个数字都能回溯到年报的档案。

报告只给生意层的事实结论，不给投资判断：不判断贵贱，不预测未来，不给买卖建议。

## 报告结构

1. 生意模式：做什么、怎么赚钱、护城河在哪。
2. 历年经营决策：管理层历年做了什么、怎么判断。
3. 资本回报分析：沿钱的旅程写连续叙述，从资本投入到回到资本回报分配。
4. 数据：证据表、口径与来源。

## 读法

读者是第一次看这家公司的个人投资者或研究员，快速判断这家公司是否值得深入研究。

## 资本回报分析

沿"钱的旅程"写连续叙述：资本从股东手里进来，经过利润、现金流两级蒸发，最后以分红或留存的形式回到股东。每一节都遵循同一原则——多期累积、滚动看，不点评单年；只拆解过去，判断留给读者。方法依据见 `docs/course.md`（姜国华《财务报表分析要点》）。

### 1. 长周期总账：上市以来股东的年化回报

穿透式检验，先算总账再拆细账：

```
年化收益率 = (当前市值 + 历年累计分红) ÷ 累计股东投入，再开年数次方
累计股东投入 = 原始投入 + IPO + 配股 + 增发 + 可转债
```

- 上市多年、年化回报仍健康，就是好；多年都不好，至少说明过去这些年不咋好。如实呈现结果，不解释、不预测。
- 输出：累计投入、累计分红、当前市值（按报告日）、年化收益率，每个数字标注来源年报页码。

### 2. 回报的成色：ROE 及其分解

- 历年 ROE、ROA（利润 ÷ 创造利润所占用的资本），多期累积看趋势，不纠结单年波动。
- 分解 ROE：高 ROE 是靠经营还是靠杠杆（杜邦分解到权益乘数）。靠杠杆的高 ROE 要标注。
- 冗余资产处理：大股东占款、长期挂账应收、闲置资产在分母里但不贡献分子，扭曲所有回报率——识别出的冗余资产单独列出，并在叙述中说明其对 ROA 的稀释。

### 3. 两级蒸发漏斗

沿"利润 → 经营现金流 → 股东拿到的钱"找漏点，两级分开写：

- **漏斗一：利润收不回现金。** 净利润与经营现金流历年对比（占收入比口径）；长期背离必留痕——列出背离年份并回溯当时的应收、周转率变化。应收账龄结构、两年以上应收占总资产比例是已验证的风险信号，单独成表。
- **漏斗二：现金到不了股东。** 经营现金流覆盖投资后的自由现金去了哪里：分红、还债、还是再投到低回报项目里空转。看"经营+投资"能否自平衡、是否长期靠筹资输血。

### 4. 分饼图：收入在各利益方之间的分配

每 100 元收入的去向表（营业成本、研发/销售/管理/财务费用、税金、政府补助冲减、净利润），多期并列。两个解读只写到事实层：

- 成本费用收入比 = 股东对各利益方的讨价还价能力，是护城河的财务落点；
- 经营性损益（靠人吃饭，可持续）与财务性损益（公允价值变动、投资收益、汇兑，靠天吃饭）分开列，不把靠天的部分算进经营的成色。

### 5. 留存资本的效率：一元检验

- 每期留存利润（净利润 − 分红）对应同期 ROE / 增量资本回报的变化：留存的一块钱，是否挣回了一块钱的增量利润。
- 增量资本回报（多期滚动，避免单年噪声）与资本成本的关系只摆事实：回报率是升是降，写清楚趋势，不判贵贱。

### 6. 表外与隐藏项：标注而非计价

资产负债表读不到的，显式标注，不估值、不写进回报率：

- **隐形资产**：品牌、人、专利、渠道——只列出"哪些护城河要素落不进报表科目"，作为未入账项提示；
- **低报资产**：涨价前存货、自持物业等，一句话提示；
- **隐形负债**：环保、未决诉讼、期权衍生品、对外担保——逐项从附注扫描，写"未在表内确认的义务"；
- **权益水分**：其他综合收益中未变现的浮盈浮亏。

### 7. 异常留痕：纵向与横向对比

测谎只做两个方向，程序直解、模型只负责解释定位：

- **纵向**：历年毛利率、费用率、周转率的突变点列出来；
- **横向**：与同行同指标的重大差异列出来。
- 突变与差异本身不是结论，叙述中只写"变化发生在哪、伴随什么业务事件"（财务与业务相互验证），把解释和判断留给读者。

### 8. 脆弱点清单（V）

用前七节的事实素材，回答一个问题：这家公司什么是"半夜惊醒因素"——单点依赖（客户、原料、政策、担保圈）、现金流自平衡依赖再融资、利润依赖靠天损益等。每条脆弱点必须挂到前文的证据（某年某表某页码），不允许出现没有证据支撑的泛泛风险套话。

### 附：数据需求与输出规则

- 核心输入：历年年报的利润表、资产负债表、现金流量表、附注（应收账龄、担保、诉讼、承诺事项、股本变动）。
- 每个数字标注物理页号（`<!-- page N -->` 口径），与生意模式、经营决策节同一套引用规范。
- 所有比率由程序从原始报表数字直解计算，模型只负责解释与叙事组织；算不出的写"看不出来"，不猜。
- 单年数据只进表格与图表，叙述一律写多期趋势。
