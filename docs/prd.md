# Cagent PRD — AI 版《穆迪手册》与《价值在线》

## 产品目标

替价值投资者省下翻阅公司的时间。输入一家公司的历年财报，产出一份能快速读完、每个数字都能回溯到年报的档案。

报告只给生意层的事实结论，不给投资判断：不判断贵贱，不预测未来，不给买卖建议。

## 报告结构

1. 生意模式：做什么、怎么赚钱、护城河在哪。
2. 历年经营决策：管理层历年做了什么、怎么判断。
3. 资本与回报：沿钱的旅程写连续叙述，从资本投入到回到资本提供者（股东/债权人）。
   - 资本从哪来、投到哪：股权/债权/租赁/留存；运营资本、长期资产、并购、表外义务；代价是否如实计入（折旧减值、冗余占款）；
   - 回报：ROE/ROIC 与增量资本回报；高回报是否靠杠杆；与资本成本比较；
   - 利润质量：经营 vs 财务/一次性；扣掉维持性投入（折旧摊销代理）才是真钱；股东份额看每股；
   - 现金：净现比与调节，背离由什么造成；
   - 分配：分红/回购/留存/还债；留存过没过一元检验（账面口径，调整增发/回购/OCI）。
   写法：开头 3–5 个关键数；后段结论能用前段证据解释；多期滚动，不看单年；主要判断给反证，判断留给读者；不预测、不估值。
4. 数据：证据表、口径与来源。

## 读法

读者是第一次看这家公司的个人投资者或研究员，快速判断这家公司是否值得深入研究。
