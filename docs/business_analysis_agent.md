# 商业模式分析 Agent 设计

输入一份年报，回答商业模式问题，产出阅读友好的报告

商业模式问题空间：谁付钱、为何付、凭什么它收得到、垫钱还是占钱、能滚多大、什么会杀死它。
问题清单由 agent 对着这家公司自行决定，不凑数、不死板

## 分工

- LLM 负责读懂：读文本、理解、总结、判断
- 程序负责记数：数字机械保真，LLM 不默写数字
- 答案在理解处成立：叙述给故事，原页数字锚定每个量

## 通读

- 答案从通读全卷的理解中长出来，不从单点裁剪中拼出来
- 读完之前不知道什么和什么相连，检索式取回的是断章不是理解

## 笔记

笔记极简，只两栏，是 agent 读 300 页时不迷路的那张纸

- 索引：哪页讲了什么，一行一条，只记有什么不记内容
- 钩子：没想通的、要回核的，每条挂着去哪看

理解不落盘：存下的理解会漂移过时，指针不会。理解发生在回读的刹那

## Agent loop

读页、维护索引/钩子、带钩子回读，三种动作交替，无阶段之分

收敛 = 钩子连续两轮零变化（无疑问新增、无需回核）
硬上限兜底，到顶必停；残余疑问如实标注，失败可见

## 报告

收敛后，agent 拿定稿索引回源精读相关页，当场写报告
素材在眼前，数字照抄当下读到的，不跨页搬运

## 纪律

- 答不了是合法答案，"年报未披露"优于编造
- 引用即回源
- 弱模型的错在交替循环中活不过两轮：每步任务小，错误下一轮自己看得见
